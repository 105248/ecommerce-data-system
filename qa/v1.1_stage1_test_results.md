## 5. 关键修复记录（验收中发现并修复）

| 问题 | 根因 | 修复 |
|---|---|---|
| raw 查询 current 期全 NULL | raw WHERE 只覆盖上期区间（p_ps~p_pe） | 改为 p_ps~p_ce（全范围），CASE 内 previous 保持 p_ps~p_pe |
| scope 域循环引用 | `resolve_scope(rs.scope)` 引用自身 | 改为 VALUES(18 scope) × LATERAL resolve_scope |
| product 单对象排名=1 | 排名子查询基于 entity 过滤后的 metrics（先筛选后排名） | 新增 `all_raw`（全量）+ `all_metrics` + `full_rank`（全量 DENSE_RANK），快照行 LEFT JOIN full_rank |
| carrier 商品卡差异 | 未排除 special_overlap 行（全域投放时段/标准+品牌投放） | raw 加 `account_channel NOT IN ('全域投放时段','标准+品牌投放')`，与 carrier_period aggregation_allowed 一致 |
| varchar(100) vs text 返回类型 | meta.shop.shop_name 是 varchar | 输出列显式 `::text` |
| RETURNS TABLE 列名与 PL/pgSQL 变量歧义 | shop_name/domain_name_cn 等输出列遮蔽表列 | 子查询加表别名前缀 |
