## 3. 隔离机制清单

- **物理隔离**：同一 core 表 + shop_id 区分（无第二套表，如 douyin_deal_daily_personal 不存在）
- **业务键隔离**：9 表 uk_*_business 唯一索引全部含 shop_id
- **导入隔离**：importer `--shop-id` 显式指定；未知店铺 → UNKNOWN_SHOP 失败
- **覆盖隔离**：replace_period 按 shop_id + 日期 + 表 限定
- **查询隔离**：mart/MCP 全部经 `p_shop_name` → meta.shop JOIN 解析 shop_id
- **中文层隔离**：同一中文 View + 店铺名称字段，可筛选两店
- **覆盖独立**：get_data_coverage 按店返回（个护 30 天独立，不因官方店有 30 天而误判）
