# 09｜应用层边界冻结

> 数据库最终架构收口检查｜封版版 V1.0｜第十一阶段
> 检查日期：2026-08-08｜生效范围：本文件发布后所有新功能

---

## 一、冻结声明

**数据库从此不再为页面、飞书协作或 AI 文案无限扩张。**

以下内容 **明确不再进入数据库**（不做表、不做函数、不做字段）：

| 类别 | 具体内容 | 归属层 |
|---|---|---|
| 页面布局 | 布局结构、栅格、组件顺序、页面骨架 | Growth Web 前端 |
| 页面专属排序 | 单个页面的排序偏好（区别于 rank_* 正式排名） | 前端状态 |
| ¥ / % 显示 | 货币符号、百分比格式、千分位、小数位 | 前端格式化 |
| 收藏 | 用户收藏商品/页面/报表 | 用户偏好存储（非经营库）|
| 飞书任务 | 任务卡片、待办、指派、截止提醒 | 飞书（Lark）任务系统 |
| 机器人提醒 | 机器人推送规则、频率、渠道 | 机器人服务层 |
| 页面导航 | 菜单结构、路由、面包屑 | Web 路由/导航配置 |
| 导出样式 | 导出 Excel 的列宽、样式、合并单元格 | 导出服务层 |
| AI 自由文本 | 自然语言解释文案、AI 生成段落 | AI 层（ai_layer/）|
| 聊天上下文 | 会话历史、用户提问上下文 | 对话服务存储 |
| 前端交互 | 交互状态、表单草稿、模态框状态 | 前端状态 |

## 二、边界判定规则（新需求自检）

新增数据库对象（表/函数/视图/字段）必须回答以下问题，**任一命中则禁止入库**：

1. 该数据是否只为**单个页面**服务？（→ 前端）
2. 该数据是否只影响**展示格式**（¥/%/颜色/字体）？（→ 前端）
3. 该数据是否属于**用户个人偏好/收藏/会话**？（→ 用户层存储）
4. 该数据是否属于**飞书任务/机器人/聊天**？（→ 飞书生态）
5. 该数据是否是 **AI 生成的自由文本/解释**？（→ AI 层）
6. 该数据是否在 MCP / Backend / Web **多处复用**且为**确定性经营计算**？
   - ✅ 是 → 允许入库（mart）
   - ❌ 否 → 禁止入库

## 三、允许入库的唯四类别

只有以下情况允许新增数据库对象：

```text
1. 真实业务事实（core）
2. 主数据 / 映射 / 指标规则 / 配置（meta）
3. 导入 / 数据质量 / 审计（audit）
4. 跨系统复用的确定性经营计算与正式结果（mart）
```

## 四、现状核对（2026-08-08）

盘点确认：**当前数据库不存在任何应用层内容**（无页面布局表、无收藏表、无导航配置、无 AI 文案表）。`format_percent_2` 为唯一展示格式化函数（仅供 SQL 层展示，不承担数学计算），建议保持 INTERNAL 定位。

## 五、F0.5 约束传递

- Growth Web：所有展示格式在**前端**完成，数据库只返回原始数值与中文 COMMENT
- 飞书入口：任务/提醒/卡片在**飞书侧**完成，数据库不承载
- Backend API：仅透传 mart 计算结果 + 做 wrapper 层参数校验，**不写经营公式**
