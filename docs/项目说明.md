# ecommerce-data-system · 项目说明

电商经营数据中台：Excel 原始文件 → PostgreSQL 五层架构 → WorkBuddy/OpenClaw/MCP 查询。

## 目录结构

```
D:\ecommerce-data-system
├── raw_files              原始Excel文件（禁止改名/删除）
│   └── douyin             抖音原始文件
│       └── 弹动官方旗舰店\2026\2026-06\
├── sql                    数据库建表脚本（01~04 已就绪）
├── importer               Excel导入程序（第二步开发）
├── mcp_server             MCP查询服务（后续开发）
├── config                 配置文件
├── logs                   导入和运行日志
├── backups                数据库备份
└── docs                   字段字典和使用说明
```

## 数据库五层架构

| Schema | 中文含义 | 用途 |
|---|---|---|
| `meta` | 基础配置层 | 店铺、平台、指标字典 |
| `audit` | 导入审计层 | 记录导入了什么文件 |
| `stg` | 临时处理层 | 导入过程中暂存数据 |
| `core` | 正式数据层 | 清洗后的抖音数据 |
| `mart` | 经营分析层 | Agent查询汇总数据 |

## 命名规范

- **英文技术字段名** + 完整中文注释 + 中文数据字典
- 不建议直接使用中文字段名；英文名更稳定，中文注释负责可读性
- WorkBuddy/OpenClaw 返回结果时再转换为中文名称
