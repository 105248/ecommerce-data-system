## 二、经营进度页（核心）

- 日报 / 周报 / 月报 tab（同一模板结构，仅周期不同）；默认日报、锚点=数据库最新业务日（当前 **2026-08-10**）
- **固定 18 行经营报表**（抖音整体 / 抖音弹动官方旗舰店 / 抖音弹动个人护理旗舰店 × 整体/自营直播/自营商品/达人直播/达人短视频/橱窗）
- 6 指标：成交金额 / 成交退款金额 / 结算金额 / 退款率 / 投放消耗 / 投放费比（页面无括号技术口径）
- **成交金额唯一长期显示目标**：实际 + 测算目标 + 进度条 + 完成率 + 时间进度 + 领先/落后%（不用 pp）
- 其他指标**仅未达标才提示**（⚠ 超目标/低于目标进度/超预算），达标完全不显示
- 覆盖不完整（coverage_complete=false）→ **暂停目标判定**（防漏数据假预警）
- 顶部：区间 / 数据截至 / 完整度 / [导出]（CSV）/ 未达标提醒条（全部达标不显示）

## 三、目标系统（新）

- **meta.business_target**（PG16）：`UNIQUE NULLS NOT DISTINCT(platform_code, shop_id, target_month, business_type_code, metric_key)`（修复 shop_id=NULL 时 UNIQUE 失效导致 upsert 重复的 bug）
- 目标规则：PROGRESS_MIN(成交) / CUMULATIVE_MIN(结算) / CUMULATIVE_MAX(退款上限/投放预算) / RATE_MAX(退款率/费比)
- 人工只维护**月目标**；日目标=月÷当月天数；周目标=月÷月天×周落月天数（**跨月周分段**，下月目标未设→"本周目标不完整"）；**RATE 类不按天折算**
- 截至数据日应完成 = 月目标÷月天×当日为月第几天（月报）；成交金额完成率=实际/期间目标，时间进度=已过/总
- 权限：`growth_workspace_target_writer`（仅 meta.business_target SELECT/INSERT/UPDATE，禁 core/mart/DDL/删除业务事实，目标软删 enabled=false）；`growth_workspace_reader` 保持只读

## 四、待关注页

[全部][目标][异常] tab：目标异常（来自目标系统，严重=落后≥10%/关注）+ 数据异常（智能层 FRESH 才展示）；可读文案 + [查看数据]；**不显示 Risk/Opportunity Score 等复杂评分**。

- **达人/账号**：保留现有正式能力
