## 二、周期进度模板（V1.0 无利润计算版）

**三张表**：抖音整体 / 抖音弹动官方旗舰店 / 抖音弹动个人护理旗舰店（全名，无简称）
**每表 6 行**：店铺整体 / 自营直播 / 自营商品 / 达人直播 / 达人短视频 / 橱窗
**每行 6 指标**：成交金额 / 成交退款金额 / 结算金额 / 退款率 / 投放消耗 / 投放费比

**字段口径**（与既有 mart 白名单一致）：
- 成交退款金额 = SUM(transaction_refund_amount_pay_time)（支付时间）
- 投放消耗 = SUM(ad_spend_shop_bound)（店铺被投）
- 投放费比 = SUM(ad_spend_shop_bound)/SUM(settlement_amount)（剔除退款、店铺绑定）
- 退款率 = SUM(refund_amount_pay_time)/SUM(user_pay_amount)

**经营类型归并**（sale_scope × carrier_type，ad_period 仅取'不限'防重复）：
- 自营直播 = 自营×直播；自营商品 = 自营×(短视频+商品卡+其他+图文)
- 达人直播 = 合作×直播；达人短视频 = 合作×(短视频+图文)；橱窗 = 合作×(商品卡+其他)
- 店铺整体 = 全部×全部（平台汇总行，精确匹配，非聚合叠加——R3 修复了初版"全 NULL 导致交叉汇总行叠加"的 bug）

**周期语义**：日报=今天（基于系统最新业务数据日 MX）、周报=近 7 天（MX 基准）、月报=**自然月**（8/1-8/31 整月，数据覆盖到哪显示到哪，不随 MX 截断）
