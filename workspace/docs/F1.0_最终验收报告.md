## 一、F1.0-A 经营驾驶舱：✅ PASS
- 首页：7 指标卡（当前/上期/变化）+ 成交趋势（SVG，DAILY_FACT）+ 风险 TOP5 + 机会 TOP5 + Watchlist + 店铺贡献 + Coverage

## 四、F1.0-D 权限/收藏/导出/体验：✅ PASS
