## 二、第一步：公网 HTTPS 地址（三选一）

### 方案 A：cpolar 内网穿透（推荐，最快体验）
1. 注册 cpolar 账号：https://www.cpolar.com（免费版即可）
2. 安装 Windows 客户端，登录后在「验证」页复制 authtoken
3. 创建隧道：**本地地址 `127.0.0.1:8001`、协议 `http`**
4. cpolar 返回一个 `https://xxxx.cpolar.cn` 地址 → **拿这个地址给飞书用**
5. ⚠️ 免费版每次重启隧道地址会变化，飞书里配好后若地址变了需同步更新（体验阶段可接受；长期建议方案 C）

### 方案 B：frp 内网穿透（需自有公网服务器）
- 服务器跑 `frps`，本机跑 `frpc` 配置子域名，反向代理到 127.0.0.1:8001，配 TLS 证书
- 地址稳定，适合中期使用

### 方案 C：云服务器正式部署（长期推荐）
- 任选一台云主机（阿里云/腾讯云等），部署：Python 3.13 + backend 代码 + `uvicorn` + Nginx 反代 + 域名 TLS 证书
- 地址永久稳定，F1.0 正式上线走这条

> **拿到 https 地址后先自测**：手机 4G/5G 网络下浏览器打开该地址，能看到工作台首页，再进飞书配置。

## 三、第二步：飞书开放平台创建「网页应用」

1. 打开 https://open.feishu.cn → **开发者后台** → **创建企业自建应用**
2. 填写：应用名称「抖音智能经营工作台」、图标、描述
3. **应用能力** → 添加 **网页应用** → 主页 URL 填第一步得到的 `https://xxxx/`
4. 权限：**本阶段不申请额外权限**（页面打开不需要 open_id；飞书免登识别身份是后续增强项，见第五节）
5. **版本管理与发布** → 创建版本 → 提交发布 → 管理员审核通过
6. 发布后可在飞书工作台看到应用图标；管理后台可设置**可见范围**（默认仅创建者可见）

## 四、第三步：把凭证交给我配置

发布后从开发者后台「凭证与基础信息」复制 **App ID / App Secret**，填入：

```
D:/ecommerce-data-system/workspace/backend/.env
FEISHU_APP_ID=cli_xxxx
FEISHU_APP_SECRET=xxxx
```

（模板已备好：`backend/.env.example`，占位符 `[FEISHU_APP_ID]`/`[FEISHU_APP_SECRET]`）

配置后重启 Backend，我负责端到端验证。

## 五、第四步：验证（我来做）
