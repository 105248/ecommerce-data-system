# F1.0.1 真实源数据缺口清单（SOURCE_NOT_AVAILABLE，R1 一致性版）

> 判定标准：gap_type=SOURCE_NOT_AVAILABLE，reason 区分 LOCAL_SOURCE_FILE_NOT_FOUND（本机扫描未发现）与 NEED_MANUAL_CONFIRMATION（平台能否导出待人工确认）

| 页面 | 能力 | reason | 处置 |
|---|---|---|---|
| 商品卡 | 商品卡来源构成(曝光/点击/来源分解) | LOCAL_SOURCE_FILE_NOT_FOUND：本机扫描范围未发现商品卡来源构成/流量来源文件；平台能否导出待人工确认(NEED_MANUAL_CONFIRMATION) | 人工确认平台导出能力后走标准接入流程；不造数据 |
| 投放 | 计划/账户/单元/预算/状态 | LOCAL_SOURCE_FILE_NOT_FOUND：本机无计划级源文件；平台计划级导出能力待人工确认(NEED_MANUAL_CONFIRMATION) | 保持 KNOWN LIMITATION；不从店铺总投放推算计划级 |
| 退款 | 退款原因/售后原因 | LOCAL_SOURCE_FILE_NOT_FOUND：成交分析无退款原因列；平台退款原因明细导出能力待人工确认(NEED_MANUAL_CONFIRMATION) | 页面明确'当前数据源不支持退款原因分析'；AI不得猜原因 |
| 直播 | 直播场次/直播商品/时段明细 | LOCAL_SOURCE_FILE_NOT_FOUND：单载体构成sheet仅含商品卡内容(53024行/599内容)；平台直播明细导出能力待人工确认(NEED_MANUAL_CONFIRMATION) | 禁止用频道汇总冒充明细 |
| 短视频 | 单视频/视频素材级 | LOCAL_SOURCE_FILE_NOT_FOUND：单载体构成sheet无短视频内容；平台单视频/素材导出能力待人工确认(NEED_MANUAL_CONFIRMATION) | 禁止用频道汇总冒充明细 |
| 搜索 | 搜索成交/关键词 | LOCAL_SOURCE_FILE_NOT_FOUND：本机扫描范围未发现搜索核心数据文件；平台'本店搜索核心数据'导出能力待人工确认(NEED_MANUAL_CONFIRMATION) | 人工确认平台导出能力后走标准接入流程 |
| 素材 | 素材列表/表现 | LOCAL_SOURCE_FILE_NOT_FOUND：本机扫描范围未发现素材分析文件；平台素材分析导出能力待人工确认(NEED_MANUAL_CONFIRMATION) | 人工确认平台导出能力后走标准接入流程 |

## 处置

- 直播/短视频：渠道整体（scope=直播/短视频）READY；明细禁止用频道汇总冒充明细（页面已标注）
- 其余：页面明确'当前数据源不支持XX分析'；AI 不得猜测
- 全部等待人工确认平台导出能力后走标准接入流程（Source→mapping→core→mart→whitelist→API→Web）
