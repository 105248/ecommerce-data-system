# F0.5-C｜最小 Web + 飞书工作台接入说明

> 验收时间：2026-08-08 ｜ 访问地址：http://127.0.0.1:8001

## 一、Web 页面（同源静态托管，零 CORS）
| 页面 | 路由 | 内容 |
|---|---|---|
| 工作台首页 | `/` | 范围/日期/经营口径选择 + 7 项 KPI（成交/用户支付/退款/结算/退款率/投放消耗/投放费比）+ Coverage + 风险 TOP3 + 机会 TOP3 |
| 系统状态 | `/system-status` | Web/Backend/Database 状态 + 店铺数 + 关键函数样例 |
| 数据状态 | `/data-status` | 每店最早/最新日期/天数/行数/DAILY_FACT |

- 页面数据全部来自 `/api/v1/*`（Backend → PostgreSQL mart），**无任何前端计算**
- 显示层中文 Label（成交金额/退款率…），API 字段保持英文（transaction_amount/refund_rate…）
- 比例显示：refund_rate=0.1972 → 19.72%；效率原值 2.39（不显示 239.48%）

## 二、飞书网页应用接入（F0.5 最小）
### 1. 飞书应用配置（企业自建应用）
- 创建「抖音智能经营工作台」网页应用
- **网页应用 URL**：`https://<部署域名>/`（本地开发 `http://127.0.0.1:8001/`）
- 应用权限：仅需要身份识别（获取用户 open_id），**不申请多维表格/消息权限**（F0.5 飞书只做入口与身份）

### 2. 身份映射（Backend 配置层，不扩张数据库）
- `app/main.py` 中 `FEISHU_USERS`：open_id → (role, shops)
- 角色：ADMIN / MANAGEMENT / OPERATOR / VIEWER
- 店铺权限：open_id 映射到可见 shop_code 列表
- **未映射 open_id → 401 UNAUTHORIZED**；无权限店铺 → Backend 返回 FORBIDDEN
- F1.0 可迁移至 `meta.app_user*`（F0.5 按基线不扩张数据库）

### 3. 入口验证流
```
飞书工作台 → 抖音智能经营工作台 → /feishu/auth?open_id=xxx → 识别角色+店铺
→ 进入首页 → 选日期/店铺 → /api/v1/* → PostgreSQL → 展示
```

## 三、部署安全
- PostgreSQL 5432 仅 Backend 可访问（本机 127.0.0.1），不暴露公网
- Backend/Web 经 HTTPS 暴露（生产需反向代理 + TLS）
- Secret（DATABASE_PASSWORD / FEISHU_APP_ID / FEISHU_APP_SECRET / SESSION_SECRET）全部环境变量管理，禁止 Git 提交 .env
- 开发阶段：本地 PostgreSQL + 本地 Backend + 本地 Web + 安全 HTTPS 入口
