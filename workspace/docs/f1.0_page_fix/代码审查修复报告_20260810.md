## 四、过程中额外发现并修复

1. **变量遮蔽（UnboundLocalError）**：共享化 `_shop_name` 时 `shop_name = shop_name(shop_code)` 局部变量遮蔽导入函数 → 函数改名 `resolve_shop_name`，全部端点恢复。
2. **筛选器改动不生效**（历史遗留）：`location.hash = G.page` 在 hash 不变时不触发 hashchange → 页面不刷新；改为 onchange 直接 `renderFilters()+renderPage()`（浏览器实测选店即时生效）。
