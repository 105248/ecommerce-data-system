# Stage5 回答模板（answer_templates）

> 所有数字必须来自 MCP 工具结果；格式按展示规范。

## 1. 简单数字（金额）

```text
2026年6月，弹动官方旗舰店商品卡用户支付金额为 {X}（{Y}万元），占全店 {Z}%。
```

## 2. 简单数字（比例）

```text
2026年6月全店退款率为 {X}%（数据库原值 0.xxxx）。
```

## 3. 环比（金额）

```text
本期（{cur_start}~{cur_end}）为 {X}，上期（{prev_start}~{prev_end}）为 {Y}，
环比 {增/减} {Z}（{rel}%）。
```

## 4. 环比（比例，优先百分点+相对变化）

```text
退款率从 {prev}% 升至/降至 {cur}%，变化 {pp} 个百分点，相对变化 {rel}%。
```

## 5. TOP 排名

```text
按用户支付金额排名（2026年6月）：
1. {name}：{amount}
2. {name}：{amount}
...
（共10名）
```

## 6. 增长最快

```text
增长最快TOP{n}（2026年{period}）：{name} 本期 {cur}、上期 {prev}、绝对变化 {abs}、相对变化 {rel}%。
注意：上期基数较低时相对变化可能放大。
```

## 7. 排名变化

```text
{name}：本期第 {cur_rank} 名，上期第 {prev_rank} 名，排名{上升/下降/持平} {n} 位。
（本期新进入的标"本期新进入"，不强行计算增长率。）
```

## 8. 贡献度（必须说明分母）

```text
2026年6月，商品卡用户支付金额为 {X}，占全店（deal全店TOTAL） {Y}%。
商品{product}：商品域内占比 {a}%（分母=各商品carrier=全部平台独立TOTAL之和），
全店占比 {b}%（分母=deal全店TOTAL）。两个口径分母不同，不混用。
```

## 9. 账号

```text
账号排名（2026年6月，合作）：1. {account} {amount} ...
说明："更多账号"为合作聚合桶，代表未展开的合作账号合计，不是具体达人。
```

## 10. 类目

```text
按三级类目排名（2026年6月）：1. {l1}>{l2}>{l3} {amount} ...
```

## 11. source_only（多日）

```text
当前不能精确汇总2026年6月的{指标}。数据库保留每日平台源值，但现阶段没有已确认的
跨期分子/分母，因此系统不做日率平均。
```

## 12. 数据覆盖不完整

```text
当前数据库没有完整覆盖该时间段（覆盖{coverage_days}/{expected_days}天），
不能把现有结果当作完整周期结论。
```

## 13. 今天无数据

```text
当前数据库尚无 {date} 的数据（最新数据截至 {max_date}）。
```

## 14. 无数据 / 空结果

```text
该查询当前无可用数据。
```

## 15. 同比

```text
当前系统尚未建立同比专用接口，暂不支持同比比较。如需同比分析，请确认是否纳入后续开发计划。
```

## 16. 为什么（数据拆分，非因果）

```text
从现有数据拆分看，{期间}的下降/增长主要集中在：
- 载体：{carrier} 变化 {x}
- 商品：{product} 变化 {x}
- 类目：{category} 变化 {x}
说明：以上为数据层面的拆分观察，不代表因果结论。
```

## 17. 工具错误 / 参数错误

```text
抱歉，{tool} 调用失败：{error_type} - {message}。请检查参数后重试。
```

## 18. 拒绝编造

```text
我无法在未调用数据工具的情况下给出这个数字。请允许我通过经营数据工具查询后回答。
```

## 19. 投放表现（V1.0.1，get_advertising_summary）

```text
{期间} {范围} 投放表现：
- 投放消耗(店铺被投)：{金额}
- 投放消耗(店铺绑定)：{金额}
- 投放贡献成交金额：{金额}
- 投放贡献成交占比：{比例}%
- 投放费比(剔除退款、店铺绑定)：{比例}%
- 综合费比(剔除退款、店铺绑定)：{比例}%
- 投放效率(店铺被投)：{倍数}（倍数，非百分比）
- 投放效率(店铺绑定)：{倍数}
- 全店效率(店铺被投)：{倍数}
- 全店效率(店铺绑定)：{倍数}
（口径：仅 ad_period=不限；综合费比/效率为加权源比率，非日率平均）
```

## 20. 投放环比（V1.0.1，compare_advertising）

```text
{本期} vs {上期}（{范围}）：
- 投放消耗(店铺绑定)：{本期} → {上期}，{绝对}，{相对}
- 投放贡献成交占比：{本期}% → {上期}%，变化 {百分点}个百分点（{相对}）
- 投放效率(店铺被投)：{本期} → {上期}，{绝对}（不输出百分点）
（效率变化只给绝对+相对，不给百分点）
```

## 每日简报（V1.1 Stage5/6）

```
【今日抖音经营简报】（{start}~{end}）
- 经营概览：抖音整体成交 {X}（环比 {rel}）；官方店 {X}（{rel}）、个人护理店 {X}（{rel}）。
- TOP5 风险：
  1. {实体}｜{异常类型}（等级 {P}，评分 {score}）：影响约 {impact}，{排查方向}。
  ...
- TOP5 机会：
  1. {实体}｜{机会类型}（等级 {O}，评分 {score}）：机会质量排序分，非成功概率。
  ...
- Watchlist：{coverage/mapping/证据不足项}
- 覆盖：{enabled}/{covered} 家启用抖音店铺{（非完整整体，结果仅供参考）}
```

## 为什么 Priority 高（V1.1 Stage6）

```
该风险排第 {n} 主要因为：业务影响 {impact}（占比 {pct}）、异常等级 {severity}、已持续 {days} 天、
诊断置信度 {conf}、实体战略权重 {weight}。主异常 {type}，关联子异常 {sub}。
（分数由系统计算，AI 仅解释不重算）
```

## 为什么 Opportunity 高（V1.1 Stage6）

```
该机会评分 {score}（{level}）：Stage4 机会分 {op}、成交规模 {vol}、增长持续性 {persist}、
可用维度权重 {weight}、风险安全 {risk}。基准：同域 peer（{pool}，{n} 个）。
（机会质量排序分，非未来成功概率；如并存退款风险会提示）
```

## 排查清单（V1.1 Stage6）

```
当前异常集中在 {primary_stage} 环节。可优先排查：
- {category=CHECK_CLICK：主图、标题、价格/促销、首屏表达}
- {category=CHECK_CONVERSION：详情页、评价、规格、价格}
- {category=CHECK_TRAFFIC：投放预算、素材、时段}
- {category=CHECK_REFUND：履约、物流、商品质量}
- {category=CHECK_AD_EFFICIENCY：投放结构、人群、创意}
以上为排查方向，不代表已证明原因。
```
